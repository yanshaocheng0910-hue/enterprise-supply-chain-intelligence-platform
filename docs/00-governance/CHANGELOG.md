## 2026-09-21 — 按角色汇总的只读待办中心

- 新增 `/api/v1/work-queue`，从既有预警、需求、计划、订单、收货和对账状态实时生成待办，不建立第二套任务状态。

## 2026-09-21 — 可审计的本地 AI 经营分析报告

- 新增 BUYER/MANAGER 可见的“经营分析报告”，聚合订单、库存、供应商、对账和预警事实，形成经营摘要、分主题分析和可跳转的优先行动。
- 本地 Qwen 只对闭集章节进行风险排序；精确事实、数字、风险等级和行动入口全部由确定性规则生成。模型输出不合规时显式规则降级，不将幻觉写入报告。
- 新增 Flyway V6 `supply_chain_analysis_report`，持久化事实快照、报告、provider/model/prompt、降级原因、SHA-256 数据指纹、幂等键和创建人；生成动作纳入操作审计。
- 新增 Spring Boot 三个报告接口和 FastAPI 内外部分析接口；供应商和管理员不能读取企业经营报告，生成仅对 BUYER/MANAGER 开放。
- 最新回归：Spring Boot 55/55、FastAPI 23/23、前端生产构建通过；真实 API 及浏览器按钮均生成本地 Qwen 辅助排序报告，桌面/390px、Noto Sans SC 计算样式、0 控制台错误通过，证据 UI-19/UI-20。
- 当前 H2 已迁移 V6；既有 MySQL 164/164 只覆盖 V1—V5，V6 MySQL 与 Compose 仍待复验，不提前合并口径。
