## 使用规则

每条意见都使用 `UAT-版本-序号`，例如 `UAT-090-001`。界面观感、文案和操作不顺也要记录，不只记录程序报错。没有复现和回归证据的口头修改不能标记完成。

## 单条反馈模板

- UAT 编号 / 提交日期：
- 测试版本 / 环境 / 账号角色：
- 所属需求、页面和接口：
- 问题或建议：
- 复现步骤、期望结果、实际结果：
- 截图或请求号 / 日志路径：
- 类型：缺陷 / 易用性 / 新需求 / 数据 / 文案
- 优先级：阻断 / 高 / 中 / 低
- 复现结论与根因：
- 修改文件及数据库/API/状态机影响：
- 新增或更新测试编号：
- 自动回归结果：
- 文档和论文影响：
- 最终状态 / 用户复验日期：
