## UAT-090-001 — 失效会话停留业务页且错误图标异常放大

- 提交日期：2026-09-21；环境：Windows 本机，BUYER，仓库页。
- 问题：旧 JWT 失效后页面仍保留登录外壳，显示 `[UNAUTHORIZED] 请先登录`；通用警告 SVG 未限尺寸，形成覆盖页面的巨大红色感叹号，并与空状态叠加。
- 根因：响应拦截器只透传 401，没有清理本地会话或回到登录页；通用 `.inline-error` 未限制直接子 SVG 尺寸；仓库页错误态与空态不是互斥分支。
- 修复：401（登录请求除外）统一清理 token/session/demo 标记，保留原路径并跳转登录；登录页显示“登录已失效”；限制错误图标为 16px；仓库失败态增加重试并与加载/空态互斥。
- 自动回归：生产构建通过；真实浏览器把 token 改为无效值后自动跳转，`luna_access_token` 与 `luna_session` 均为空；计算字体仍为 Noto Sans SC Variable。
- 影响：仅前端认证恢复和错误态，不改变后端权限规则、数据库或业务状态机。
- 最终状态：已修复，等待用户复验截图场景。

## UAT-090-002 — 数据导入缺少明确的系统文件选择与真实下载

- 提交日期：2026-09-21；环境：Windows 本机，BUYER，数据导入页。
- 问题：用户希望点击后出现 Windows“选择文件”窗口；原上传区入口不够明确，“下载模板”和“查看错误明细”仅显示提示，并未生成文件；前端标注 20 MB、后端实际仅 10 MB。
- 根因：上传交互完全依赖组件默认行为；两个下载动作是占位实现；Axios 实例全局写死 `application/json`，导致 FormData 预览真实请求返回 500/415 不匹配；上传大小配置不一致。
- 修复：增加可点击/可拖放的原生 CSV 选择器、已选文件名/大小/移除与格式校验；移除全局 JSON Content-Type 让浏览器生成 multipart boundary；提供四类真实模板；错误明细导出 UTF-8 CSV；前后端统一为 20 MB；错误行改为中文可读文本。
- 自动回归：前端生产构建通过；Spring Boot 54/54；浏览器成功打开 file chooser，选择 `inventory.csv` 后服务端完成预览并返回 2 条真实引用错误；模板 `inventory.csv` 与 `import-errors-*.csv` 均真实下载且内容复核正确；390px `scrollWidth=viewport=390`。
- 影响：前端数据导入页、Axios 默认头、四个公开模板和 Spring multipart 上限；不绕过服务端“预览—确认—写入”边界。
- 最终状态：已修复，等待用户复验文件选择和下载体验。
